# 베트맨 캡처 — 2026-10-27 KST 경기 (127회차, 입력하지 않음)

- 출처: 사용자가 보낸 베트맨 NBA 목록 화면 캡처 5장. 크롤링하지 않았다.
- 사용자 메모: "캡처 시각: 2026-10-27 (KST 모두 각각 마감 30분전)", "회차: 127회차".
- 이 세션이 캡처를 읽은 시각: 2026-10-27 14:4x KST. 아홉 경기 모두 시작(08:00~11:00 KST)이 지난 뒤였다.
- **JSON을 만들지 않았고, 기록한 것은 없다.**
  - 읽은 시각에는 아홉 경기가 모두 시작해, 마감(시작 시각 이전)이 지났다. 입력해도 검사에서 모두 "마감 지남"으로 제외된다.
  - 화면의 "결과보기" 칸에 최종 점수가 있다(예: 샬럿 vs 워싱턴 110:103, 언더오버 칸 213 = 110+103). 경기가 끝난 뒤의 화면으로 보이며, "마감 30분 전" 메모와 맞지 않는다. 어느 쪽이 맞는지는 확인하지 못했다.
  - 이 화면에는 마감 시각이 없다(경기 머리에 시작 시각만 있다). 그래서 "마감 30분 전"을 시각으로 바꿀 수 없고, 마감 규칙도 이번에는 관측하지 못했다.

## 핸디캡 기준선의 방향
- 화면: "홈 vs 원정"으로 홈팀이 앞이고, 핸디캡 줄의 "H x"는 **홈팀에 붙는다**. 부호는 화면 그대로다.
- 근거(이 캡처의 결과 칸): 핸디캡 줄의 결과는 "홈 점수 + H : 원정 점수"다. 샬럿 110 − 1.5 = 108.5, 오클라호마시티 125 − 8.5 = 116.5, 밀워키 110 + 4.5 = 114.5.
- 입력 JSON의 `line`도 같은 규칙이다. 홈팀 기준 H를 부호 그대로 넣고, `home`(승) = 홈 점수 + H > 원정 점수다(`engine/markets.js`, `engine/picks.js`).
