# 베트맨 마감 관측 표

- 2026-10-28 사용자 결정 4에 따라 만든 표다.
- 관측이 쌓이기 전에는 규칙을 모두 **"미확정"**으로 표시한다.
- **평가 경로는 이 규칙을 쓰지 않는다.** 마켓마다 입력된 마감 시각으로 정하고(`engine/trigger-time.js` evalPath), 확정 화면에 마감과 경로를 함께 보인다.
- 출처 구분
  - "화면": 캡처에 마감 시각이 보인 경우
  - "전달": 사용자가 말로 알려 준 경우(화면 근거 없음)

## 규칙 상태 (모두 미확정)
| 시작 시각대(KST) | 화면 관측 | 전달 | 상태 |
|---|---|---|---|
| 09:00 전 | 2개 캡처(10-23, 10-27 15:18), 모두 전날 23:00 | 10-27 경기(08:00대) 전날 23:00 | **미확정** |
| 09:00 이후 | 2개 캡처가 서로 다름: 10-24는 시작 시각, 10-28은 전날 23:00 | 10-27 경기(09:00~11:00) 전날 23:00 | **미확정** |

- 회차와 마감의 관계(같은 회차 안에서 마감이 같은지)도 미확정이다. 10-23 캡처에는 회차 번호가 없었다.
- 새 캡처가 오면 이 표에 한 줄씩 더한다.
- 2026-10-28 입력 방침: C 경로 경기(마감이 실행 A·B 최종 시각 이전)는 JSON에서 빼고, 제외 목록에 사유와 함께 적는다. 관측은 이 표에 그대로 남긴다.
