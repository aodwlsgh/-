**3.5% 초과 경기와 원인**: 2024-25 0경기, 2025-26 35경기, 2026-27 0경기. 전체 목록과 원인은 `docs/reports/p2-summary.json`의 `seasons.*.possessions.over35`에 있다.
- **34경기 원인: heave.**
  - 2025-26부터 ESPN 박스 FGA에서 heave가 빠진다. 그런데 heave로 끝난 공격권은 실제로 있으므로, 박스 기반 추정식이 경기당 heave 수만큼 공격권을 적게 센다.
  - 이 34경기는 heave가 1~4개이고, heave를 FGA에 되돌리면 모두 3.5% 이하가 된다(예: SAC@WSH 4.64% → 2.44%, heave 4).
  - 진단: heave를 되돌린 추정식으로 보면 2025-26은 평균 1.21%, 95백분위 2.50%, 3.5% 초과 1경기다. 2024-25(1.13%, 2.35%)와 같은 수준이 된다.
  - 합격 판정에는 사용자가 정한 ② 그대로의 수치를 썼고, 이 진단은 참고용이다.
- **1경기 원인 미확정: 2025-11-22 ATL@NO**(4.91%, heave 보정 시 3.79%)
  - 박스와 플레이바이플레이는 야투 1개 차이 외에 일치한다.
  - 공격권 종료 유형 분포(성공 77, 수비 리바운드 71, 턴오버 25, 자유투 18)도 평소 경기와 비슷하다.
  - 추정식 자체 오차(0.44·FTA 근사 등)로 추정한다.

**홈·원정 차 > 2** (2024-25 8경기, 2025-26 5경기)
- 연장은 쿼터마다 점프볼로 시작해 차이가 연장 한 번에 최대 1씩 정상적으로 생긴다. 이를 허용하면(2 + 연장 수) 2024-25 4경기, 2025-26 3경기만 남는다.
- 남은 7경기는 모두 차이 3이다. 같은 팀 공격권이 연달아 기록된 경계 사례로 보인다(ESPN 기록 순서 문제). 공격권 오차는 모두 기준 이내다.

**P2에서 고친 공격권 파서 버그**(모두 재현 테스트 추가)
1. 앤드원 자유투가 득점보다 먼저 기록된 경우(4점 플레이)
2. 앤드원 자유투가 득점보다 1초 늦게 찍힌 경우
3. "Technical" 표기 없는 테크니컬 자유투(플롭 테크니컬 뒤 1-of-1)
4. take foul·clear path 자유투 뒤 공격권 유지
5. 상쇄된 더블 테크니컬 뒤 2구 자유투를 테크니컬로 오판하던 문제
6. 득점·턴오버 뒤에 늦게 기록된 공격 리바운드
7. 박스 팀 집계가 깨진 경기(2024-10-25 NO@POR, 야투 −22)는 추정식 재료를 플레이바이플레이로 대체(`box_totals_inconsistent`)

- **B 경기 324/324가 경기 당일 17:50 이후·20:50 이전 PDF(20:00 또는 20:45)를 쓴다.** 17:50 PDF를 그대로 쓴 B 경기는 없다.
