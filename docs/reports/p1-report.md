## 3. 야투 +10 / 3점 +11 차이의 원인 — **규명**
- 원인: **"Heave Jump Shot"**(유형 id 282). 쿼터 종료 직전의 하프코트 너머 슛이다.
- 2025-26부터 ESPN은 이 슛을 따로 분류하고, **박스스코어 FGA·3PA에서 뺀다.**
  - P0 표본의 불일치 13팀이 heave 13건과 1:1로 맞았다(나머지 1팀은 데이터가 깨진 LAC@CHI).

- 처리
  - heave를 분류 `heave`로 따로 두고, 야투·3점 집계, 슛 구역, 성공률 모델에서 제외한다.
  - 공격권 종료로는 센다.
- 결과: 야투 3,627 = 3,627, 3점 1,476 = 1,476으로 **완전 일치**한다.
