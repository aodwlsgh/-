# P4 보고 — 공격권 시뮬레이터

> **P3 모델이 시장 대비 우위라는 근거는 아직 없다.** 시뮬레이터는 P3 레이팅을 그대로 쓰므로 이 점은 P4에서도 같다.

- 작성: 2026-10-22
- 평가 시즌: 2024-25(개발 시즌)만 썼다. 2025-26은 계속 봉인 상태다(`data/model/test-openings.json` 열람 기록 없음).
- 코드
  - `engine/sim.js`: 시뮬레이터
  - `jobs/p4.js`: 점검(`mean`, `calibrate --stage 1|2`, `var`)
  - `test/sim.test.js`: 테스트 14개, 전체 152개 통과
- 결과 파일
  - `docs/reports/p4-mean.json`, `p4-calibration.json`(1단계), `p4-calibration-2.json`(2단계), `p4-var.json`
  - 선택값: `data/model/latent.json`

## 1. 한 일
- 설계 §7.1~7.3을 공격권 단위 몬테카를로로 구현했다.
- P3 직접 예측(`engine/predict.js`)과 같은 레이팅·출전 시간 계획·사용률 정규화·리그 득점 환경·홈 이점을 쓴다.
  - 라인업마다 사건 확률(턴오버, 자유투 2개, 구역별 슛, 공격 리바운드로 이어질 확률 ρ)을 P3 비율에서 풀어 쓴다. 그래서 규칙과 잠재 변수를 끄면 시뮬레이션 평균이 P3 예측과 같아진다.
  - 출전 시간 계획은 1분 단위 48칸에 배분한다. 선발은 각 하프 시작에 들어간다.
  - 출전 확률이 1보다 작은 선수는 시뮬레이션마다 결장 여부를 뽑는다. 결장하면 같은 포지션에 출전 시간을 재분배한다.
- 게임 상황 규칙(설계 §7.3)
  - 클러치 파울: 4쿼터 마지막 60초, 3~8점 뒤진 팀이 즉시 파울한다.
  - 가비지 타임: 4쿼터 8분 이하 20점 차 또는 25점 차면 벤치 라인업으로 바꾸고 경기 속도 +3%
  - 연장: 5분
- 난수: xoshiro128**. 시드를 고정하면 결과가 같다.

  - 조치: 정규시간 경기 속도 계수 `regPace` = 0.99172(설계 §7.2 변경 기록)

## 4. 추가 점검 ② 시뮬레이션 표준편차 = 실제 분산 ±10% (사용자 요청)
- 비교 대상
  - 시뮬레이션: 경기별 표준편차의 제곱평균제곱근
  - 실제: 2024-25 실제 잔차(실제 − 시뮬레이션 평균)의 표준편차
- 최종(`p4-var.json`, 1,230경기 × 1만 회, 규칙·잠재 변수 켬)

| 항목 | 시뮬레이션 | 실제 | 비율 | 기준 0.9~1.1 |
|---|---|---|---|---|
| 점수 차 | 14.07 | 14.26 | **0.986** | 통과 |
| 총점 | 17.54 | 18.10 | **0.969** | 통과 |

### 4.1 맞춤 과정 (2024-25만 사용, 튜닝 장부에 누적)
- 원래 설계(독립 공격권 + 팀 슛 감각 + 경기 속도 잡음)로는 점수 차 SD가 **16.5**로 실제 14.3보다 15% 컸다. 실제 경기에는 앞선 팀의 효율이 떨어지는 점수 효과가 있는데 독립 공격권 모델에는 그것이 없다.
- **1단계(24회)**: 공유 슈팅 환경 {0, 0.03, 0.06} × 점수 효과 kappa {0, 0.75, 1.5, 2.25} × 팀 슛 감각 {0, 0.02}
  - kappa 0.75만으로도 점수 차 SD가 10.2(비율 0.71)로 지나치게 줄었다.
  - 공유 슈팅 환경과 팀 슛 감각은 총점 SD만 키웠다(이미 1.04).
  - 최선은 모두 0(점수 차 비율 1.15, 불합격). 간격이 너무 넓었다.
- **2단계(10회)**: kappa {0.1, 0.15, 0.2, 0.25, 0.3} × 경기 속도 잡음 {0, 0.03}, 나머지는 0

| kappa | 점수 차 비율(속도 잡음 0 / 0.03) | 총점 비율(0 / 0.03) |
|---|---|---|
| 0.10 | 1.065 / 1.064 | 0.969 / 1.041 |
| 0.15 | 1.023 / 1.023 | 0.971 / 1.042 |
| **0.20** | **0.986** / 0.987 | **0.972** / 1.041 |
| 0.25 | 0.954 / 0.954 | 0.972 / 1.045 |
| 0.30 | 0.920 / 0.921 | 0.974 / 1.043 |

- 선택: kappa 0.2, 경기 속도 잡음 0, 팀 슛 감각 0, 공유 슈팅 환경 0. 목적함수는 |log 점수 차 비율| + |log 총점 비율|이다.
- 이어서 규칙을 켠 평균 총점이 P3 예측과 같아지도록 regPace = 0.99172로 정했다.
- 설계 §7.2와 다른 점은 설계 문서에 기록했다(**승인 필요**, §7 결정 1).

## 5. 발견한 문제 — 접전 결과(5점 이내)와 연장이 실제보다 적다
점수 차의 **평균과 표준편차는 맞지만 분포 모양이 다르다.** 승5패의 '5'(연장 포함 5점 이내) 확률에 바로 영향을 준다.

| 구간(P3 예상 점수 차 절댓값) | 경기 | 시뮬레이션 P(5점 이내) | 실제 비율 |
|---|---|---|---|
| 전체 | 1,230 | 21.8% | 25.1% |
| 3점 미만 | 390 | **24.0%** | **31.3%** (표준오차 약 2.3%p) |
| 3~8점 | 527 | 22.7% | 25.6% |
| 8점 이상 | 313 | 17.7% | 16.6% |

- 연장 비율도 시뮬레이션 2.3%, 실제 4.9%(60경기)다.
- 원인 분석(단위 예시, 4만 회)
  - 설계 §7.3의 클러치 파울 규칙이 접전 결과를 **줄인다.** 앞선 팀은 자유투로 점수를 늘리고, 뒤진 팀은 평소처럼 공격하기 때문이다.
  - 홈 이점 0인 대결에서 P(5점 이내)가 규칙 없이 29.6%, 클러치 파울을 켜면 26.0%다. 3점 차 결과 비율은 2.9% → 2.1%로 준다.
  - 실제 경기에서는 뒤진 팀이 파울 뒤 3점을 노리고, 앞선 팀도 자유투를 놓쳐 점수 차가 좁혀진다. 이런 막판 행동은 설계에 없다.
- **이 상태로는 '5' 결과의 확률이 체계적으로 낮게 나온다.** 그래서 '승'·'패'(6점 이상) 쪽 EV가 부풀려진다. 승5패 픽을 켜기 전에 해결해야 한다(§7 결정 2).

### 5.1 클러치 파울 규칙을 끈 진단 (1,230경기 × 2,000회, 다른 값은 그대로)

| 구간 | 실제 | 규칙 켬 | 규칙 끔 |
|---|---|---|---|
| 전체 | 25.1% | 21.8% | 26.8% |
| 3점 미만 | 31.3% | 24.0% | 29.5% |
| 3~8점 | 25.6% | 22.6% | 27.8% |
| 8점 이상 | 16.6% | 17.7% | **21.9%** |
| 연장 비율 | 4.9% | 2.3% | 2.6% |

- 규칙을 끄면 접전 예상 경기는 실제에 가까워지지만, 일방적 예상 경기에서 '5점 이내'가 지나치게 많아진다(5.3%p, 표준오차 약 2.1%p).
- 끄면 총점도 P3 예측보다 −0.99 낮아진다. regPace를 다시 맞춰야 한다.
- **어느 쪽도 구간 전체를 맞추지 못하고, 연장 비율은 둘 다 실제의 절반이다.** 실제 막판 행동이 빠져 있기 때문으로 본다.
  - 동점이나 1~3점 차에서 마지막 슛을 노림
  - 뒤진 팀의 3점 위주 공격
  - 3점 앞선 팀의 파울
- 참고: 8점 이상 구간의 차이에는 시뮬레이터 모양뿐 아니라 P3 예상 점수 차 자체의 보정(기울기)도 섞여 있다. 이 부분은 P5 보정(로지스틱 기울기)에서 다룬다.

## 7. 결정할 것
1. **설계 §7.2 변경 승인**
   - 점수 효과 kappa 0.2 추가
   - 정규시간 경기 속도 계수 regPace 0.99172 추가
   - 팀 슛 감각 0
   - 경기 속도 잡음은 2025-26 대신 2024-25로 정해 0
2. **접전 분포(§5) 처리** — 승5패 '5'와 작은 핸디캡 기준선에 영향이 있다.
   - **(가) 권장: P5 보정 단계에서 결과 확률을 보정한다.**
     - 계획의 `engine/calibrate.js`에 승5패 세 결과(6점 이상 승 / 5점 이내 / 6점 이상 패)의 다항 로지스틱 보정을 더한다. 입력은 시뮬레이션 확률과 예상 점수 차다.
     - 2024-25 전진 평가 예측으로만 적합하고, 2025-26 개봉 때 그대로 적용해 검증한다.
     - 시뮬레이터는 그대로 둔다.
     - 장점: 매개변수 2~4개로 단순하고, 이미 계획된 승패 확률 보정과 같은 방식이다.
     - 단점: 보정이 크면 시뮬레이터 모양을 신뢰하기 어렵다.
   - (나) 막판 행동을 시뮬레이터에 추가한다(마지막 슛, 뒤진 팀 3점 비중, 3점 앞선 팀 파울).
     - 2024-25의 구간별 '5점 이내' 비율과 연장 비율에 맞춘다.
     - 설계 §7.3 확장이고 튜닝 실행이 수십 회 늘어난다.
   - (다) 해결 전까지 승5패 '5' 결과는 기록 전용으로 두고 승패·핸디캡만 평가한다.
   - (가)로 하고, 2025-26 개봉에서도 '5' 보정이 실패하면 (나)로 가는 순서를 제안한다.
3. **P4 완료 처리** — 사용자 요청 점검(평균 일치, 표준편차 ±10%)과 설계 §14.1 점검은 모두 통과했다. 결정 1·2가 끝나면 P5(2025-26 단 한 번 개봉)로 간다. 개봉 전에 결정 2의 보정 방식을 설계 §14.4에 사전 등록한다.
