# 단일 픽 200개 도달 전망 — A·B 경로만 (2026-10-28)

- 2026-10-28 사용자 결정 "입력 방침 변경" 5에 따라 다시 계산했다.
- C 경로(마감이 실행 A·B보다 이른 경기)는 입력하지 않는다. 그래서 해제 조건의 200개는 A·B 경로만으로 채워야 한다.

## 입력
- **주당 승패 픽(설계 §9.5)**
  - 2024-25(24.7주, 1230경기)에서 추정했고, 승패 마켓만 센다.
  - 보수 확률은 하향 공식 `p − 0.1·|p − 0.5|`(지금 코드 `engine/picks.js` pCons)이다.
  - 시장이 단순 기준모델만큼 정확하다고 가정하면(낙관): 주 13.4~15.2개
  - 시장이 우리 모델만큼 정확하다고 가정하면(우위 없음): 주 0개
- **A·B 경로 비율:** 마감이 시작 시각인 경기의 비율이다. 표본이 작아 세 경우로 나눴다(`docs/betman/deadline-observations.md`).

  | 경우 | A·B 비율 | 근거 |
  |---|---|---|
  | 관측 전체 | 24% (6/25경기) | 화면 16경기 + 사용자 전달 9경기 |
  | 화면 관측만 | 38% (6/16경기) | 10-23 캡처, 10-27 15:18 캡처 |
  | 상한 | 76% (938/1230경기) | 09:00 KST 이후 시작 경기가 모두 시작 시각 마감이라고 가정. 2024-25 일정 기준. 10-28 관측(09:00·12:00 시작도 전날 23:00)과 맞지 않아 상한으로만 쓴다 |

## 결과 (승패만, 낙관 가정)
| A·B 비율 | 주당 A·B 픽 | 200개까지 |
|---|---|---|
| 24% | 3.2~3.6 | 55~62주 |
| 38% | 5.0~5.7 | 35~40주 |
| 76%(상한) | 10.2~11.6 | 17~20주 |
| (우위 없음 가정) | 0 | 도달 못 함 |

- 2024-25 정규 시즌은 24.7주였다. 2026-27은 10-20에 시작했으므로, 시즌 길이가 비슷하면 남은 기간은 약 23.5주다.
  - 2026-27의 종료일은 데이터로 확인하지 못했다. 일정 파일은 10-26까지만 수집됐다.
- **관측 비율(24~38%)이면 이번 정규 시즌 안에 A·B 경로 200개에 도달하지 못한다.** 상한(76%)일 때만 시즌 안에 도달할 수 있다.
- 8주 조건은 200개보다 먼저 채워진다.

## 한계
- 핸디캡·언더오버 픽은 추정에 넣지 않았다. 과거 기준선 자료가 없어 추정할 근거가 없다. 실제 픽 수는 이 표보다 많을 수 있지만, 얼마나 많을지는 모른다.
- 주당 픽 수는 과거 베트맨 배당 없이, 시장 확률을 가정해 만든 추정이다. 첫 실측(기록 전용 4주) 뒤 실제 배당으로 갱신한다.
- A·B 비율은 사흘치 25경기로 정했다. 캡처가 쌓이면 다시 계산한다.
